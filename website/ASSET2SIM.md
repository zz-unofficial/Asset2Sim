# Asset2Sim website

This site uses [Academic Project Astro Template](https://github.com/RomanHauksson/academic-project-astro-template). Its original attribution and CC BY-SA 4.0 license information are retained in the template README and site footer.

Use Node 24, then run `npm ci` and `npm run build` from this directory. The root GitHub Actions workflow builds with the Pages origin and repository base path and deploys `website/dist`. In repository Settings → Pages, select GitHub Actions as the source. Push website changes to the default branch or run the workflow manually.

Edit `src/paper.mdx` for project content. Components for images, video, equations, tables and 3D models remain in `src/components`; add research media and measured results as they become available. The `/studio/` page is a placeholder for future browser-based simulation.
