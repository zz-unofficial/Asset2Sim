# 浏览器端 MuJoCo Reference Box PoC

Studio 复用 `debug_box_run03/reference/model/scene.xml` 及其资产，来源是 Menagerie 修订版 `370c43965323c0944b433b202aac5058b5f907a9` 和本项目的 Reference Box 场景。UR5e 与 Robotiq 的上游许可证分别随场景保存在 `website/public/studio-scene/`。MuJoCo 采用 `@mujoco/mujoco` 4.0.1 默认单线程构建。对象是自由刚体，夹爪内部联动约束保留；抓取通过执行器、碰撞和摩擦实现，IK 计算使用独立数据副本。

## 本地运行

使用 Node 24：

```bash
cd website
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端给出的首页并滚动到 Interactive Demo；资源会在浏览前文时加载。也可直接访问 `/studio/`。等待显示“可以操作”，交互区域出现在页面中且页面处于前台时即可操作，无需点击画面；按住 W/S、A/D、R/F 移动末端，U/O、I/P、H/L 分别绕参考姿态的 X、Y、Z 轴正/负旋转；J/K 闭合/张开，0 重置。鼠标拖动旋转相机、滚轮缩放。可按 F 下降到方块中部，按 J 闭合，按 R 抬升，再按 K 松开。具体时长取决于设备性能及画面状态，应观察实际位置与接触。

部署子路径的生产构建：

```bash
npm run build -- --site https://zz-unofficial.github.io --base /Asset2Sim
```

状态每秒显示加载时间、渲染 FPS、每步物理耗时、按键到 IK 目标被接受的延迟、方块高度及双指和桌面接触。按钮可下载本次页面会话的每秒 JSON 样本。加载时间包含模型获取、编译、场景和渲染初始化；每步耗时不含控制计算和渲染。按键延迟不含机器人实际运动响应，接触为布尔状态而非力测量；采样不适合检测短时接触。浏览器调度和渲染负载可能使仿真时间慢于真实时间。

## 初步验证及边界

2026-11-14，Chrome 无头模式、软件 WebGL、GitHub Pages 子路径静态预览，自动键盘输入：页面加载约 5.40 s，约 26 FPS；记录的 `mj_step` 约 0.027–0.048 ms/步。下降后闭合出现双指及桌面接触，抬升后双指接触且离桌，采样方块中心从约 0.049 m 到 0.241 m；松开后双指无接触、重新接触桌面（中心约 0.025 m，落地后姿态可能改变）。一次测得按键至 IK 接受约 39 ms；性能是此环境一次观察，不能代表普通用户设备。

原生 MuJoCo 3.3.5 的 Reference Box 自动键盘测试也观察到双指受力、离桌、释放后接触桌面；固定轨迹试验三次成功，最大抬升 108.6 mm，详见 `robot_grasp.md`。浏览器使用 MuJoCo 4.0.1、不同键盘时长与采样口径；以上仅支持接触顺序的定性一致，不能视为相同轨迹、力或数值结果的严格复现。尚需在用户实际浏览器、GPU 和键盘上检验；暂未测试触屏和移动设备，也未测量接触力或真实输入到物体运动的端到端延迟。
