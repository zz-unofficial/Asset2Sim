## 几何表现与指标区分度

本轮采用最长边为 1 的归一化，FS@0.1 允许最大边长 10% 的表面距离。GSO 有 9/24 个对象、Omni 有 13/24 个对象在该阈值取得 1；FS@0.2/0.5 更接近完全饱和。因此高 F-score 主要支持整体形状接近，不能据此确认文字、薄壁、孔洞或小部件准确。

GSO 的 CD 均值/中位数为 0.03273/0.02664，较差对象拉高均值。`Frozen_Scrabble_Jr` 的 CD=0.08412、FS@0.1=0.48685，重建厚度明显偏大；卷尺、家具组、文件架也是几何误差较大的对象。几何误差最小的 Wilton 长盒 CD=0.00431，但对照图仍可见贴图模糊和背面内容猜测，说明几何与纹理需要分别评价。

Omni 的 CD 均值/中位数为 0.04523/0.04683，误差较普遍，并非单个极端案例造成。其 FS@0.1 略高于 GSO，但 CD 更大：一个统计距离是否越过阈值，一个统计实际距离，二者排序不同并不矛盾。

## 外观差距包含评测流程影响

Omni 的 PSNR 范围为 7.46–11.57dB，整体偏低。查看 [Omni 对照图](../../results/metrics/sf3d_paper_public/run01/omniobject3d_qualitative.png) 与保存的变换、材质后，发现两项需要优先处理的流程问题。

1. **图像对齐出现明显缩小。** 相比归一化后的刚体对齐，图像阶段的尺度 ICP 在 GSO 上平均缩放至 0.894 倍，Omni 上为 0.721 倍；`omni_book_book_002` 缩放至 0.423 倍。对照图里的书因此明显小于参考图。当前 `icp(scale=True)` 使用单向最近邻拟合且未限制尺度，存在通过缩小预测来降低拟合误差的风险。该变换只用于图像指标，不影响本表 CD/F-score；它对图像分数的贡献需要固定尺度与受约束尺度的对照来量化。
2. **参考与预测材质存在亮度口径差异。** Omni 24 个参考 GLB 中，23 个的 `baseColorFactor` 为 `[102,102,102,255]`，即基础色系数约 0.4；参考贴图会再乘该系数。加载器的 OBJ→PBR 转换会继承 diffuse 参数，预测资产则使用模型输出材质。对照图中参考物体偏暗、重建偏亮，PSNR 因而混入材质转换、光照和模型去光照的差异。目前不能把全部差距归为纹理重建失败。

部分书籍封面和床的输入方向也不自然，需核对扫描数据的原始向上轴与统一相机约定。现有“最大轮廓面积”规则保证可重复，但不保证选到语义正面。几何对齐还可能交换近对称对象的正反面；[SF3D 附录 A2](https://arxiv.org/html/2408.00653v1#A2) 也将这种纹理朝向歧义列为图像指标的限制。

## 数据组成与论文对照

Omni 子集实际包含书籍 16、腰包 6、电池 1、床 1。书籍占 66.7%，平均 CD=0.0501、PSNR=8.5609dB、LPIPS=0.4590；腰包对应 0.0359、10.1986dB、0.2620。总体均值因此主要反映书籍案例，不能代表完整 OmniObject3D 的类别分布。

论文报告 GSO/Omni CD 为 0.098/0.090，PSNR 为 21.247/20.134dB。本次 CD 较小、图像分数较低，反映的不是同一设置下的质量提升或退化：对象清单、归一化与渲染参数不同，且当前已发现图像对齐与材质口径问题。论文原值用于定位复现目标；后续跨模型结论来自统一数据和评测设置下的配对比较。

## 下一步顺序

1. 保留 run01，建立独立的图像评测诊断配置：比较固定尺度和受约束尺度对齐，记录缩放、轮廓覆盖与正反面关系，先确认投影一致。
2. 核对 Omni 扫描方向和 OBJ 材质；分别明确贴图颜色评测与完整 PBR 渲染评测的设置。如果改变了条件输入，再另建数据版本并重跑对应生成。
3. 保留论文阈值作为对照，同时增加尺度明确的严格 F-score 或距离分位数，提高几何比较的区分度。
4. 评测口径稳定后，复用同一清单接入 SPAR3D、TRELLIS.2；扩充 Omni 类别覆盖，再开展碰撞和交互比较。

当前最可靠的结论是：SF3D 在本机能够稳定、亚秒级生成纹理资产；复杂细部、厚度和不可见区域有明显误差。模型间精度排名和论文图像分数对齐，需要先完成上述评测校准。
