# Asset2Sim：已有模型复现与仿真评测实验框架

## 1. 目标与课程对应

采用 SF3D、SPAR3D、TRELLIS.2 的官方预训练权重，在统一单图输入和物理适配流程下比较生成资产的几何、外观、碰撞表现及资源开销。当前阶段完成推理复现、固定基线对照与误差分析，形成可复核的实验结果。

SF3D 的论文表 1 / 表 A1 复现采用独立的 [论文评测协议](sf3d_paper_reproduction.md)，先完成 GSO、OmniObject3D 公开子集及原论文指标。下文的米制尺度、碰撞阈值与仿真任务服务于课程跨模型比较，两种评测分别保存配置和结果。

课程依据为 [课程要求.md](../../课程要求.md)。重点精读课程清单中的 TRELLIS.2 与 SPAR3D，结合 SF3D、CoACD 梳理技术路线。交付包括精读笔记、方法比较表、可运行代码与配置、公平对照、关键图表、8 页以上报告和 12–18 页 PPT；截止为 2026-12-20 23:59。

当前已完成 SF3D 环境、权重、推理适配、开发数据和 12 个输入的生成。SPAR3D、TRELLIS.2 按统一接口接入后开展正式比较。开发约定见 [AGENTS.md](../../AGENTS.md)，SF3D 操作与已有观察见 [准备文档](sf3d_preparation.md)。

## 2. 模型与研究问题

| 模型/工具 | 实验角色 | 研究价值 |
| --- | --- | --- |
| SF3D | 基础生成模型、流程开发入口 | 直接生成带 UV 与材质的 Mesh，支持快速批量实验 |
| SPAR3D | 点云条件生成对照 | 分析不可见区域重建差异与后续交互表现的关系 |
| TRELLIS.2 | 课程指定模型、强生成对照 | 引入 O-Voxel 与复杂拓扑/PBR 资产路线 |
| 单凸包、CoACD | 固定碰撞基线 | 分析几何近似、碰撞精度与计算成本的权衡 |
| Trimesh、Blender/Pyrender、PyBullet | 检查、渲染和仿真 | 提供一致的数据与评测口径 |

- **RQ1：** 相同单图输入下，各生成模型的几何保真、资产可用率和资源开销如何权衡？
- **RQ2：** 对同一生成 Mesh，碰撞表示和分解精度如何影响接触判断、稳定性与运行成本？
- **RQ3：** 几何指标与交互表现之间是什么关系，差异集中在哪些形状、视角与处理阶段？

## 3. 流程与实现组织

```text
参考 Mesh → 受控单图渲染 → 三个模型分别生成原始 Mesh
     │                              │
     ├──────────────→ 几何/外观评测 ←─┤
     │                              │
     └→ 参考对照          固定碰撞表示 → 接触与刚体仿真
                                      │
                                  指标与误差分析
```

参考、原始生成、统一处理后几何与碰撞体分别保存。模型适配器负责官方推理；公共运行器负责输入选择、记录和结果表导出。几何、碰撞和仿真模块读取同一组对象/视角 ID，将新指标按运行与样例键关联。

- `environments/<model>/`：独立 Conda 环境与模型依赖。
- `configs/models/`：模型默认参数；`configs/experiments/`：数据清单与参数覆盖。
- `data/manifests/`：各模型共用的输入集合。
- `data/generated/<model>/<condition>/<run_id>/`：原始输出与运行记录。
- `results/metrics/`、`results/figures/`：统一表格、统计与可视化。

## 4. 数据设计

| 集合 | 规模 | 用途 |
| --- | --- | --- |
| 开发集 | 四类各 1 个对象，每对象 2 视角；已准备 8 张参考渲染图 | 接口、坐标、碰撞和任务调试 |
| 正式参考集 | 四类各 6 个，共 24 对象，每对象 2 视角 | 主定量比较 |
| 真实照片补充集 | 可选 4–6 张 | 分析实际背景处理与生成失败案例 |

四类为近似凸形、明显凹陷/容器、贯通孔/把手、细长/复杂支撑结构。对象按主要结构归类并记录附加标签。参考资产从 GSO、OmniObject3D 的许可明确子集选取，必要时补充具有明确接触真值的程序化实体；扫描与程序化样本分别统计。

清单记录对象/视角 ID、分组、类别、来源、许可、输入图片、参考网格与相机。正式对象在运行模型前选定，记录与公开训练/评测来源的已知重叠情况。

渲染统一使用 512×512 RGBA、固定背景、光照和相机参数。每个视角分别作为一次单图输入；模型内部缩放和前景处理写入各自配置。定量实验使用共享掩码，真实照片另行观察背景处理影响。

几何评测将参考与生成对象按统一规则平移并将最长边归一到 `L=0.20m`，保存尺度和坐标变换。朝向依据官方导出约定及输入相机统一，ICP 可作为单列诊断。该主实验衡量归一化几何；绝对尺度和真实物性属于后续独立问题。

## 5. 实验矩阵

| 编号 | 实验内容 | 设置与主要输出 |
| --- | --- | --- |
| E0 | 官方推理与开发闭环 | 官方样例、4 个开发对象；完成环境、生成与导出记录 |
| E1 | 三模型资产质量 | 24 对象×2 视角×3 模型，共 144 份主生成输出 |
| E2 | 固定碰撞表示 | 每份生成 Mesh 对比 4 种碰撞条件，最多 576 组碰撞输出 |
| E3 | 仿真任务 | 相同物性与初态，比较模型×碰撞条件的稳定性、接触和成本 |
| E4 | 场景/参数分析 | 按形状、视角和随机性分析；预算允许时补充 TRELLIS.2 分辨率分析 |

参考 Mesh 同样构建四种碰撞表示，用于定位绕过生成阶段后的表现。逐阶段记录生成差异、碰撞近似差异与求解器行为。

主运行固定种子 0。预选 8 个正式对象（每类 2 个）与一个输入视角，对随机采样模型补跑种子 1、2。若 SPAR3D 和 TRELLIS.2 均执行该分析，共增加 32 份输出。确定性推理的重复运行用于确认稳定性，随机运行按全部预定结果汇总。

## 6. 固定物理适配与碰撞条件

先保留原始输出，再执行统一三角化、有限值/退化面检查和固定清理规则，记录面数、连通分量与表面积变化。CoACD 的内部预处理网格、形状变化和耗时单独记录。

| 条件 | 表示 | 设置 |
| --- | --- | --- |
| C0 | 单凸包 | 每对象一个凸体 |
| C1 | CoACD 粗分解 | 归一化凹度阈值 0.10 |
| C2 | CoACD 固定默认阈值 | 阈值 0.05，作为主模型比较条件 |
| C3 | CoACD 细分解 | 阈值 0.02 |

阈值采用 `real_metric=False` 的归一化口径；固定种子、预处理、搜索预算与顶点约束。每种模型均运行相同四个条件。凸分解以多个凸体组成一个刚体的复合碰撞形状，先用开发集孔环确认导入后的孔洞结构。

## 7. 评测指标与任务

### 资产与资源

- **几何：** 对称 Chamfer-L1 与 F-score；两侧按面积各采样 20,000 点，距离除以 `L`，F-score 阈值为 `0.01L`、`0.02L`。
- **结构：** 加载率、有效顶点/面、连通分量、水密性与面数。开放表面按其结构单列，实体内外指标对满足条件的样本计算。
- **外观：** 固定评测相机下的多视图拼图和轮廓 IoU，包含输入之外的视角。
- **碰撞：** 相对输入 Mesh 的接触 FP/FN、凸体数和总顶点数；相对参考 Mesh 的端到端接触误差另列。
- **成本：** 模型加载、输入预处理、生成、导出、碰撞构建、仿真步耗时与峰值显存，统一记录单位和硬件。

### T1：放置与稳定性

对适用刚体预标注一个参考支撑朝向及两个固定小扰动，共 3 个初态；使用保证初始无穿透的统一场景高度释放，仿真 3s。

建议成功条件为末 0.5s 线速度低于 0.01m/s、角速度低于 0.1rad/s，且相对目标支撑姿态倾角不超过 15°。同时记录最终倾角、漂移、穿透和倒下后静止的情况。阈值在开发集上验证后冻结。

### T2：孔洞/凹陷探针

对适用对象预设 3 条球形探针轨迹，覆盖应通过与应阻挡两类；半径按参考孔径的固定比例确定。基于参考实体的表面距离和内外判定建立标签，并验证轨迹采样密度足以捕获薄壁接触。

FP 表示应无接触却判为接触，分母为真负例位置数；FN 表示应接触却漏检，分母为真正例位置数。另统计整条轨迹通过/阻挡行为的一致率。生成 Mesh 的内外判定不可用时，记录该项缺失及对象计数。

### T3：受控推移（选做）

在固定小子集上施加同一推杆轨迹，观察位移、旋转与穿透，用于解释接触几何的敏感性。

### 仿真控制

建议时间步 1/240s、重力 9.81m/s²、对象质量 0.10kg、横向摩擦系数 0.5、恢复系数 0、求解器迭代数 100，固定阻尼、碰撞 margin 和质心/惯性处理。

主对照采用参考实体在统一密度假设下计算并归一至统一质量的质心/惯性，同一对象各条件共用，以隔离碰撞几何差异。依赖参考的受控评测与仅用默认物性的资产流程分别成表。

## 8. 比较与统计

各模型固定一个官方推理配置，记录采样步数、分辨率、精度、简化与纹理选项。TRELLIS.2 优先使用预算可控的官方 512³ 配置。保留各方法原始输出；等面数后处理如开展，作为独立条件。

质量按同一输入清单配对，时间排名在同一 GPU、批量和计时边界下测量；碰撞与仿真统一 CPU、线程数与软件版本。不同硬件的运行分别列出设备。

同对象的视角和初态先汇总到对象，再报告总体、形状分组与对象级重采样区间。失败按推理、网格、碰撞、仿真阶段记录，计入端到端成功率；几何指标同时给出有效样本数。

用逐对象配对图、失败案例与探索性秩相关分析几何和交互之间的关系，结合阶段对照解释观察结果。

## 10. 结果组织与交付

每轮记录模型与权重版本、实际参数、输入快照、种子、设备、依赖、成功/失败及资产路径。公共 `summarize` 命令导出逐输入生成表，几何与仿真指标沿用实验、运行、对象和视角键；图表从这些记录生成。

报告主线为“方法差异→实验协议→资产质量→碰撞对照→交互结果→误差解释”。主要产物包括技术路线表、三模型主结果表、碰撞精度/成本曲线、同对象可视化、失败案例和可复跑命令。已有观察与后续实验安排分别描述，论文原始结果注明来源。
